排障路径

先连通，再鉴权，再配置客户端

  1. 配置 API base URL

    使用 OpenAI-compatible 服务根地址；扫描器会处理缺失 scheme 和尾部 /v1。

  2. 检查网络层

    DNS、TCP、TLS 和 HTTP 按顺序执行，方便定位域名、端口、证书和代理问题。

  3. 验证 API Key

    提供 Key 后请求 /v1/models。401/403 优先检查 Key、权限、账户状态和余额。

  4. 生成可读证据

    专业模式保留结构化状态；诊断报告模型包含脱敏信息，便于支持定位。

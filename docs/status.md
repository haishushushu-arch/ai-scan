# AI Scan 功能状态

本页是 AI Scan 唯一功能状态页。官网、用户手册、发布说明和维护文档只引用本页结论，不再另建完整状态表。

状态词含义：

- `可用`：普通用户可以在当前产品里完成操作，结果来自真实本机检测或真实接口。
- `部分可用`：已有真实能力，但还有 UI、接口兼容、登录态或使用边界没有闭环。
- `接入中`：代码或入口存在，但还不能承诺普通用户稳定使用。
- `规划中`：产品目标存在，当前版本不能当作可用功能宣传。

维护规则：

1. 新功能上线前必须先更新本页，再同步用户手册、官网、更新日志和 release note。
2. 不允许在其他文档复制完整状态表；需要状态时链接本页。
3. 没有 live 登录验证的账号、余额、充值和 Key 管理能力，只能写为 `接入中` 或 `部分可用`。
4. `/health`、HTML 200、页面入口或 mock 数据不能作为“用户可用”的证据。
